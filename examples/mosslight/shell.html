About this browser port

The same C++/SDL gameplay runs natively and as WebAssembly. No video streaming or remote game session. Saves use this browser’s IndexedDB and belong to this origin. Keyboard controls; mobile and Safari are untested.

The development build loads uncompressed JS and Wasm. The published demo uses an optimized, gzip-compressed release. See the port report for measured sizes and tested versions.
